The entry is a single emoji: 🫂 (people hugging).

## Why it makes a stranger smile

A hug is the warmest thing a stranger can offer without a word: comfort and
welcome in every language, never sarcastic, never romantic. Shown cold beside
another emoji with no caption, "people hugging" needs no context to feel warm
and quietly says "you are not alone".

## Run it

```sh
node main.ts
```

It resolves its own directory from `import.meta.url`, reads
`MAKEFUN_OUTPUT_DIR` (default `/output`), creates it, and writes exactly one
emoji plus a newline to `entry.txt`. No dependencies, no network.
